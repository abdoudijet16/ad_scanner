# ماسح الملفات (Doc Scanner)

Photo → scanner-style PDF. Fully offline (OpenCV.js + jsPDF).

**Automatic by default** – add a photo (gallery, files or live camera) and the app detects the page, flattens the
perspective, removes shadows, whitens the paper, straightens it, and warns if the shot is blurry or too dark.
Photos that are not paper (ID cards, pictures) keep their colours.

**Layout** – the preview takes 70 % of the screen; the bottom bar has Gallery · Files · Camera · Auto · Advanced.
**Advanced** opens a sheet to edit manually: Edges (drag corners), Look (Auto / Original / Magic / Gray / B&W),
Adjust (brightness, contrast, sharpen…), Pages (reorder / delete) and Export (page size, dpi, quality, margin).
Every page keeps its own settings.

**Languages** – English, العربية (full right-to-left layout) and Français. Tap the small globe in the header to switch; the choice is remembered, and the first launch follows the phone's language.

One web UI (`www/`) runs in:
* **Android APK** – Capacitor (Android System WebView). Built automatically by GitHub Actions.
* **Windows** – `python windows_webview2.py` (Microsoft WebView2)
* any browser – `npm run serve`

## Get the APK
1. Create a GitHub repo and upload everything in this folder (keep `.github/workflows/build-apk.yml`).
2. Open the **Actions** tab → **Build APK** (runs on every push, or press *Run workflow*).
3. Download `DocScanner-apk` from the run (or from **Releases → latest**), unzip, install `app-debug.apk`
   (allow "install unknown apps").

## App icon
The icon is generated by `python3 scripts/make-icons.py` (needs Pillow) into `assets/` and `www/icon-*.png`;
`scripts/patch-android.js` installs it into the Android project during the APK build.
